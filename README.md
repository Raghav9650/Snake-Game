# 🐍 Python Snake Game

This is a classic Snake game made using Python. 

## 🎮 How to Play
1. Download this project as a ZIP file to your computer.
2. Open the folder and run the `main.py` file.
3. Use your **Arrow Keys** to move the snake and eat the food!
